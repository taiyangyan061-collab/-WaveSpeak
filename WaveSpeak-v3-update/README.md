# WaveSpeak v3

Upload every file and the `audio` folder to the root of the existing GitHub repository.

New:
- Side-by-side model and user frequency spectra
- Daily topic rotation: ordering food, transportation, classroom, shopping, small talk, appointments, plans
- Chunk learning
- Common phrasal verbs
- Sound-design phrases
- Curated normal system voices, excluding novelty/singing voices

Important:
- Natural system speech cannot be captured by browser spectrum analysis.
- The included analyzable model audio is used for the model spectrum.
